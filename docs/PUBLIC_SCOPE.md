# Public Research Scope

This repository contains only the AI/software-engineering research suitable for public inspection.

Intentionally excluded:

- real bug-bounty targets
- vulnerability details
- scope snapshots for live programs
- credentials, cookies, tokens or private evidence
- exploit/reproduction material
- private economics and operational data
- sensitive tool configuration
- internal security-research automation

The public material focuses on model evaluation, coding-agent workflows, context engineering, verification and human-controlled orchestration.
