# Structured Agent Handoff Template

```text
PROJECT:
CURRENT OBJECTIVE:
BRANCH / COMMIT:

SYSTEM CONTEXT:
- relevant architecture
- important invariants
- components involved

COMPLETED:
- ...

VERIFIED:
- build:
- tests:
- static checks:
- manual/device checks:

DECISIONS:
- ...
- ...

DO NOT CHANGE:
- ...
- ...

OPEN ISSUES:
- ...
- ...

NEXT ACTION:
1. ...
2. ...
3. ...

ACCEPTANCE CRITERIA:
- ...
- ...

KNOWN RISKS / UNVERIFIED ASSUMPTIONS:
- ...
```

The purpose of the handoff is to make agent-to-agent or session-to-session continuation explicit and auditable.
